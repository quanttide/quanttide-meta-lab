# 命令行

命令行负责让你用得顺手。它是整套东西的外壳。

## 五条命令

`reflect add` 记结论，`reflect dep` 记依赖，`reflect test` 录反例并标记可疑前提，`reflect commit` 固化成规则，`reflect check` 检索相关规则并提醒。三个动作加一次检索，正好五条。

## 为什么保持五条

命令一一对应动作，是为了敲命令时不用想这一步该用哪条。多一条就多一次判断，判断一多，记的人就懒得记，记不下来后面全废。所以不合并、不增设。

## 是壳

命令行只做编排：收参数、调存储、调召回、打结果。它不定数据格式，那是存储的事；不做匹配判断，那是召回的事。这样以后换交互方式——加个 TUI、套一层别的接口——内核都不用动。
