# 命令行

命令行负责让你用得顺手。它是整套东西的外壳，代码在 `src/main.rs`，篇幅的九成是 `clap` 的声明。

## 两条命令

```text
reflect commit <规则> [--revises <前提>]...
reflect check [事件]
```

`commit` 把一条规则固化下来，顺手记上它修正的前提。`check` 检索：给事件就按命中比例列出相关规则，不给就列出全部。

`--store <文件>` 是全局参数，默认 `reflect.json`，可以写在子命令前后。

## 为什么只剩两条

反思的五个动作里，程序只该接两处：把产物收下来、在动手前送出去。拆解与检验是思考，写在纸上、写进规格就够了，用不着敲命令——让程序管工序，人会因为多一次判断而少记一次。

所以命令不合并、不增设：一条进，一条出。

## 是壳

`main.rs` 只做编排：解析参数、调存储、调召回、打结果。它不定数据格式，那是 `src/store.rs` 的事；不做匹配判断，那是 `src/recall.rs` 的事。这样以后换交互方式——加个 TUI、套一层别的接口——前两个模块都不用动。

`check` 只读，不落盘：查一次不该凭空生出一个存档。

## 验收

`tests/cli.rs` 用 `CARGO_BIN_EXE_reflect` 直接跑二进制，覆盖两条命令的落盘结果与输出，其中 `check_does_not_write_the_archive` 盯住只读这一条。要手工过一遍，在空目录里依次敲上面两条即可，存档就是 `reflect.json`。
