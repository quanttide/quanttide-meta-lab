## 结论

五份稿读下来，同一个范式出现五次：政治主张一律写在泛性质上，政治病理一律写成泛性质的失效。范式本身五个槽位——状态空间、动作、结构性质、扰动、保持条件——业务表达见后文。

## 两条共同规律

1. 主张落泛性质。五部著作的规范主张——该有什么制度、什么算好——都写在唯一性、共同性、交换性、对称性上，没有一部停在「有哪些对象」的枚举。
2. 病理落泛性质失效。命运、派系、内战、权力扩张、腐败是五种不同的叙事，结构上是同一件事：某个泛性质不再成立——自然变换有了障碍、商映射退化、余极限不收敛、迭代收敛到坏的不动点、交换性被打破。

## 业务表达

把范式当模板，写任何业务主张都过五步：

1. 状态空间：写下你会在其中做决定的所有状态；
2. 动作：写下能改变状态的动作，并规定顺序、规定什么叫不动；
3. 结构性质：写下你主张的那条唯一、共同、交换或对称的性质——全篇的主张就在这里；
4. 扰动：列出会让这条性质失效的情形；
5. 保持条件：写清哪些动作组合能把它维持住。

一句话：主张写成泛性质，病理写成泛性质失效，保持写成态射条件。

## 效度威胁与判定

最大的威胁是读法自带同构：五份稿由同一个助手、同一套范畴论词汇读出来，同范式可能来自读法而非文本。真正的闸门是 README 的复现检验——只给范式不给原文，换一个 AI 重做，看还能不能抽出同一条泛性质；这一步还没跑。

对照 README 四条假设，当前判定：

- 结构可抽取——成立，五个范畴抽出同一套五槽；
- 范式独立于原文可执行——未跑，是下一道闸门；
- 范式可迁移到同主题的第二份文本——初步成立，已迁到四份，但五份同属政治主题，跨主题迁移未验；
- 形式化是可选项——部分成立，五处强行映射已逐条标出，其中君主论的唯一函子与政治学的极限两条建议直接删掉再复现。
