助手 2026-11-04 起草，与《君主论》稿同一问法；结构性断言未经学术校对。

## 第一层：用范畴论的「语言」重述《社会契约论》的核心概念

- 众意（will of all）——一族个别意志，各自为源的态射；
- 公意（general will）——众意的余等化子：把重复与对立的个别意志商掉之后剩下的不可分项；
- 社会契约——从个体到共同体的满态射，也就是商映射；
- 让渡（alienation）——个体 → 共同体 → 个体的复合等于恒等；
- 主权——只在公共事务上有定义的态射集，目标对象只能是共同体；
- 派系（faction）——垄断了到共同体的态射的子对象，使商映射退化；
- 公意不会错——余等化子在公共事务上的唯一性。

## 第二层：用范畴论的结构定理分析《社会契约论》的核心论证

1. 公意是众意的商。卢梭说公意只看公共利益、个别诉求的差异必须被抹掉——范畴论说这是取余等化子，商映射的核里只剩公共项。

2. 让渡给全体而非任何个人，才保得住恒等。每个人 → 共同体 →（投影）每个人 = id；若让渡给君主，复合停在君主对象上、回不到自己，契约就退化成赠与。

3. 主权不可让渡是态射的目标限制。主权态射只能指向共同体，任何把它复合到个体对象的路径都不存在——这条路径一旦存在，就是把公共权力私有化。

4. 派系让商失效。当一个子对象垄断了到共同体的态射，公意不再是全体的商，而退化成该子对象的像；卢梭说小共和国易亡，范畴论说小对象的商容易退化。

## 第三层：一个具体的范畴论模型草图

对象：个体意志、派系、共同体、公意。
态射：表决、让渡、立法。
复合：表决的复合（个体 → 共同体 → 法律），顺序重要。
恒等态射：不参与表决的个体状态。

核心命题：公意 G = coeq(众意)，且对公共事务具终对象性质；契约可逆 ⇔ 投影 ∘ 让渡 = id；派系存在 ⇔ 商映射退化。

## 总结

把公意读作商、把让渡读作恒等保持，卢梭那句「让渡给全体而不是任何个人」就从一句格言变成可检验的条件：投影复合回去是不是恒等。这仍是隐喻性建构——终对象那一条只在公共事务上成立，是卢梭没有声明过的限制。
