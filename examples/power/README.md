# power：权力文本的范畴化与范式抽取

本方案 2026-11-04 由助手按现有素材起草，目的与假设尚未经创始人确认。

## 实验目的

验证一份文本能不能走完「范畴化 → 抽取范式」这条线：结构抽得出来，换一个人或换一个 AI 照着做，还能做出同样的东西。

## 背景

素材是 [docs/君主论.md](docs/君主论.md)——《君主论》与范畴论的映射稿，原为手机端草稿《君主论范式》（2026-11-03 记），逐字节迁入本目录，源侧已删。稿子把君主、领土、获取权力的手段、统治稳定性、命运与德性逐条映射到对象、态射、函子与自然变换，另给出权力范畴 Pow 的对象与态射定义，结尾自认「思想实验和隐喻性建构」。

同期两篇日志给出方向。2026-11-03 问的是范式能不能用范畴论表达、能不能拿去给 AI 当上下文；2026-11-04 定下口径——范畴是定义出来的东西，范式是思考方式，范畴论只作形式化的解释工具，是可选项，定性优先于定量。

工具侧已有对应概念：qtcloud-meta 的 `paradigm` 命令把本体装进范式做结构校验，范式是被检查的一方。本示例要回答的是范式从哪来。

## 实验假设

- 文本一旦被显式范畴化（对象、态射、复合、恒等齐备），它的稳定结构就能被抽成一份范式；
- 抽出的范式独立于原文可执行：只给范式，另一个 AI 能重做同一篇的范畴化，核心映射大体一致；
- 范式可迁移到同主题的第二份文本，不必为每篇重写；
- 形式化是可选项，抽不出结构的地方如实留白，不强行映射。

## 实验设计

1. 盘点素材里已显式给出的结构：概念映射表五条、结构定理应用四条、权力范畴 Pow 的对象与态射定义；
2. 把这份一次性回答压成范式——执行步骤、每步的判定清单、不适用场景；
3. 复现检验：只给范式不给原文，换一个 AI 重做《君主论》的范畴化，比对核心概念的映射一致率；
4. 迁移检验：换权力主题的第二份文本走同一流程，看范式是否还站得住；
5. 边界检验：按《范畴论在量潮体系中的适用边界》给每条映射标注「解释」或「强行」，越界的记进实验记录。

## 评价标准

| 指标 | 合格线 | 优秀线 |
| :-- | :-- | :-- |
| 范式独立成文 | 不看原文可执行，含判定清单 | 另附不适用场景与反例 |
| 复现一致率 | 核心概念映射八成一致 | 九成五以上，且无新增臆造概念 |
| 迁移 | 第二份文本走完全流程 | 抽出的结构同样可复现 |
| 形式化克制 | 无越出范畴层的强行映射 | 每条映射标明解释还是强行 |

## 边界

范畴论只在本示例内作解释工具，不进实体层与本体层。示例判有效，方法才回流 `data/` 与 `docs/`；判失败按实验室惯例直接删，不留痕。
